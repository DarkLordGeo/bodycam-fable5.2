## Deviations from the brief

The brief named Poly Haven, ambientCG and Sketchfab as the asset sources. Those hosts were blocked
from the environment this project was built in, so:

- surface textures are procedural rather than photo-scanned;
- weapons, hands and props are procedural geometry rather than downloaded models;
- the enemy has no mocap clips for shooting, hit reaction or death – those are procedural (IK and
  layered bone rotations).

These are the items to replace first for a higher-fidelity pass. Texture sets can be swapped by file
name without code changes.
