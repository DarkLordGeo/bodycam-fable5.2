# Controls

| Action | Input |
| --- | --- |
| Enter / resume / restart | Click |
| Move | W A S D |
| Look | Mouse |
| Sprint | Left Shift (forward only; cancelled by firing or aiming) |
| Crouch | C toggles, Left Ctrl holds |
| Fire | Left mouse (rifle: automatic, pistol: one shot per press) |
| Aim down sights | Right mouse (hold) |
| Reload | R |
| Assault rifle | 1 |
| Pistol | 2 |
| Swap weapon | Q or mouse wheel |
| Pause | Esc (releases the pointer) |

Notes

- Crouch-walking makes no noise enemies can hear; walking and sprinting do.
- Gunfire is heard across most of the facility.
- Health recovers slowly up to 50 after seven seconds without taking a hit.
